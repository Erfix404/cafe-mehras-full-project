# Contributing to کافه مهراس

Thanks for your interest! This is a portfolio project, but good contributions are welcome.

## Getting started

1. Fork the repo
2. Create a branch: `git checkout -b feat/your-feature`
3. Make your changes
4. Run tests: `npm run test`
5. Commit with a clear message: `feat(backend): ...` / `fix(frontend): ...`
6. Open a pull request to `main`

## What helps

- Bug fixes with a failing test first
- Performance improvements (measure before/after)
- Accessibility fixes (RTL, focus, aria)
- Design polish that follows the existing design system (`bone/night/saffron`, Lalezar + Vazirmatn)

## Code style

- Keep diffs small and focused
- No new dependencies when a few lines of stdlib/native code will do
- Persian UI strings, English code comments
- Follow the existing structure (frontend/ backend/ admin-panel/)
